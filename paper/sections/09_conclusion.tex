\section{Conclusion}
\label{sec:conclusion}

% Remaster, 3 October 2026.

We asked where the accuracy of LLM-agent AutoML comes from, and measured the
three candidates separately: the harness, the instruction file and the
backbone, with one open 31B model, eight real-world tabular tasks under
temporal shift, and eighteen Optuna-tuned reference methods as the yardstick.

The harness changes accuracy little. A fixed-stage workflow, a six-agent
system and a minimal shell agent lie within $\spanArch$ of each other on the
normalised scale once the instruction file is removed, the range one harness
covers over its own attempts, and no pairwise difference reaches
significance over the eight tasks. The harness changes everything else:
AutoDS-Tools spends $\costRatioMin\times$ the wall-clock of Terminus-2,
Terminus-2 leaves more attempts without a submission, and FEDOT.LLM can
attempt tabular tasks only.

The instruction file is what changes accuracy, and the change is
conditional. Inside the harness it was written for, from scratch, it
improves all eight tasks and lifts the system to the level of tuned
LightGBM; its library part alone reaches the level of tuned XGBoost.
Appended to Terminus-2 it ends \ktDiscLost{} of 24 trials without a
submission with its discipline part, through two paragraphs about training
time, and \ktToolLost{} of \ktToolTrials{} with its library part, through a
fit the agent does not wait for; applied where a working script already
exists it ends every attempt on \mlabWiped{} of \mlabRepeated{} tasks. An
instruction file is therefore part of the system under test and has to be
measured in each harness and from each starting point.

What separates all configurations from the strongest published method is
search over hyperparameters, which no agent performs. The best cell is
level with tuned XGBoost and every cell is well below the MLP-PLR ensemble
that leads the benchmark; the one harness whose backend searches over
models beats every published method on one task of eight
(\texttt{ecom-offers}). On three published
scientific tasks the minimal harness with the task text alone beat the
author baseline on two within minutes.

For the reading of agent leaderboards the result is direct: a leaderboard
over one harness measures the instructions that ship with it as much as the
model, and a scaffold is neutral only once its instruction file has been
measured. Two experiments follow from the traces and we have not run them:
adding hyperparameter search to each harness under the same budget, to see
how much of the gap to tuned XGBoost it closes, and disabling the repair
loop of AutoDS-Tools in both branches, to measure the cost of the
instruction file without it. All tasks, instruction files, traces and
scripts are released.
