\section{Conclusion}
\label{sec:conclusion}

% Remaster, 6 October 2026.  One paragraph per result, with its numbers.

We asked where the accuracy of LLM-agent AutoML comes from and measured
three candidate sources separately: the harness, the instruction file and
the language model. One open-weight 31B model ran under three harnesses on eight
real-world tabular tasks with temporal splits, and eighteen
hyperparameter-tuned reference methods served as the yardstick.

Without the instruction file, the mean scores of a fixed-stage workflow, a
six-agent system and a minimal shell agent are close
($\nTerminus$ to $\nFedot$ on the normalised scale) and no pairwise
difference is significant, although single tasks differ widely.
FEDOT.LLM leads on classification, where its backend starts from a boosting
ensemble, and trails on large regression tables, where it keeps an untuned
random forest. The harness decides other things: AutoDS-Tools spends
$\costRatioMin\times$ the wall-clock time of Terminus-2, Terminus-2 leaves
more attempts without a submission, and FEDOT.LLM can attempt tabular tasks
only. The harness also decides whether a library call ends in a
submission. Replacing the
language model changes the mean score by $\stautodsSmallDiff$ to
$\stautodsBigDiff$ under AutoDS-Tools and changes how many trials end
without a submission in both harnesses.

The instruction file raises AutoDS-Tools from $\nAutoDSOff$ to $\nAutoDS$,
on par with tuned LightGBM, on all eight tasks ($p=\stfileBothP$), most
where the hand-written model is furthest from tuned gradient boosting. The
gain
comes from its library part, which makes the agent hand the modelling to
LightAutoML; that part alone reaches $\nGridTool$, on par with tuned
XGBoost. Without it, both agents write one gradient-boosting configuration
and never tune it. The file does not transfer: appended to Terminus-2 it
leaves \ktBothLost{} of 24 trials without a submission, and from a working
script it leaves \mlabWiped{} of \mlabRepeated{} MLAgentBench tasks without
one. An instruction file is therefore part of the system under test and must
be evaluated in each harness and from each starting point. No configuration
reaches the strongest published method ($\nBest$).

On three published scientific tasks, the minimal harness with the plain task
text beat the author baseline on maize within minutes. The same text with
the library section cost it every attempt. A leaderboard built around
one harness measures the instruction file that
comes with it as well as the
model. Two experiments follow from the traces: adding a hyperparameter
search to the agents that write their own code, under the same budget, and
disabling the repair loop of AutoDS-Tools to measure the cost of the
instruction file without it.
