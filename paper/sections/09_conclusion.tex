\section{Conclusion}
\label{sec:conclusion}

% Remaster, 6 October 2026.  One paragraph per result, with its numbers.

We asked where the accuracy of LLM-agent AutoML comes from and measured
three candidate sources separately: the harness, the instruction file and
the language model. One open-weight 31B model ran under three harnesses on eight
real-world tabular tasks with temporal splits, and eighteen
hyperparameter-tuned reference methods served as the reference.

Without the instruction file, the mean scores of a fixed-stage workflow, a
six-agent system and a minimal shell agent are close
($\nTerminus$ to $\nFedot$ on the normalised scale) and no pairwise
difference is significant, although single tasks differ widely. The harness
decides other things: AutoDS-Tools spends $\costRatioMin\times$ the
wall-clock time of Terminus-2, Terminus-2 leaves more attempts without a
submission, and FEDOT.LLM can attempt tabular tasks only.

Accuracy follows who builds and tunes the model. An agent writing its own
code fits one gradient-boosting configuration and never tunes it. The
library instruction of the file makes AutoDS-Tools hand the modelling
to LightAutoML, which raises its score from $\nAutoDSOff$ to $\nAutoDS$ on
all eight tasks. The library instruction alone reaches $\nGridTool$, on par with tuned
XGBoost. FEDOT.LLM follows the same rule task by task: it leads on
classification, where its backend starts from a boosting ensemble, and
trails on large regression tables, where it keeps an untuned random forest.
No configuration reaches the strongest published method ($\nBest$).

The instruction file and the language model also change reliability and
cost, and the direction depends on the harness. Appended to Terminus-2, the
file adds no accuracy and leaves \ktBothLost{} to \ktToolLost{} of 24 trials
without a submission. From a working script it leaves \mlabWiped{} of
\mlabRepeated{} MLAgentBench tasks without one. A larger language model
removes the trials without a submission under Terminus-2 and adds them under
AutoDS-Tools, and the price of a Terminus-2 cell varies
\axPriceSpread$\times$ across the three models. An instruction file and a
language model are therefore part of the system under test and must be
evaluated with the harness they will run in.

On three published scientific tasks, the minimal harness with the plain task
text beat the author baseline on maize within minutes. With the library
section in the text, every attempt ended without a submission. A leaderboard built around
one harness measures the instruction file that
comes with it as well as the
model. Two experiments follow from the traces: adding a hyperparameter
search to the agents that write their own code, under the same budget, and
disabling the repair loop of AutoDS-Tools to measure the cost of the
instruction file without it.
