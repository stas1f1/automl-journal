\section{What the execution traces show}
\label{sec:mechanism}

% Remaster, 3 October 2026.  Three questions, three short subsections.

The ablations agree with one statement: an instruction pays where it
overrides a decision the model gets wrong, and costs where the model's own
default was already right. The execution traces that Harbor records for
every trial say why. We read them for three things: which tool the
uninstructed agent reaches for and whether it tunes it; which clauses of the
discipline instruction change the agent's behaviour; and how often an
instruction sends the agent into repair.

\subsection{The uninstructed agent picks the prescribed tool and never tunes it}
\label{sec:spontaneous}

The task statement of Terminus-2 names no library, only the task, the file
layout and the output format. The agent fitted a gradient-boosting model on
every TabReD task in every attempt: LightGBM in 23 of the 24 trials of
Section~\ref{sec:abl-image} and XGBoost in the remaining one, and on the
stock image it installed LightGBM itself on six of the eight tasks. That is
the family the library instruction would have named, so on tabular data the
instruction restates the default; inside AutoDS-Tools it still improves the
task metric by $\gridToolMeanU\%$ on average, because it hands the choice to
LightAutoML, which tunes LightGBM and CatBoost at its defaults.

The same traces locate the gap to tuned practice. The configuration is
hand-written and near-identical across tasks and attempts: 1\,000
estimators in all 24 trials, a learning rate of $0.05$ in 23, early stopping
on a holdout in 23, 31 leaves in the 19 trials that set a leaf count. No
search appears in any trace: no Optuna, no grid, no randomised search, no
cross-validated sweep. The published gradient-boosting rows are
Optuna-tuned over fifteen seeds; the agent writes one plausible
configuration and stops. This absence of search is what separates the agents
from tuned XGBoost and from the strongest published method. The per-task
extraction is released with the paper.

\subsection{The discipline instruction reaches the agent and leaves the score unchanged}
\label{sec:discipline}

The discipline instruction moves the task metric by $\gridDiscMeanU\%$ on
average (Table~\ref{tab:grid}). The traces of the same four cells show that
it reaches the agent. Three clauses ask it to compare against a trivial
predictor, to allocate the time budget before starting, and to keep the
variant that validates best; all three behaviours appear in every trial of
the two cells with the discipline instruction and in no trial of the two
cells without it. Two further clauses fail as a manipulation check. AutoDS-Tools inspects its
submission in 22 of 24 uninstructed trials and Terminus-2 in none; this is a
habit of the harness, and a comparison across harnesses would credit it to
the instruction. Early stopping is universal without the library and
invisible with it, because the prescribed library performs it internally.
The discipline instruction therefore switches three behaviours on in every
trial and moves the score by $\gridDiscMeanU\%$: the agent follows it, and
on tabular data its own defaults were already adequate.

\subsection{Instructions make execution fail more often}
\label{sec:friction}

AutoDS-Tools contains a repair loop, invoked when execution fails. It is
active in both branches of the MLAgentBench ablation and does not fire
equally often. The loop was not instrumented in the repeats, so the count comes from the
earlier pair of jobs, which covered all eighteen TabReD and MLAgentBench
tasks once per cell on the earlier data preparation of
Section~\ref{sec:coverage}, and we report a direction only: across those 36
runs the loop fired
18 times with the file against 12 without, and the imbalance concentrates
on the tasks where the file names a specialised library, four invocations
against none on \texttt{clrs} and three against none on
\texttt{amp-parkinsons}, both libraries whose interface the agent then
fails on. The trial artefacts name the clause behind the largest loss. The
discipline instruction tells the agent not to stop after ``an arbitrary
small budget (5 or 15 epochs is almost always badly undertrained)'' and
offers ``$\sim 100$ epochs'' as a starting point. On \texttt{clrs} the
cell without the file chose 5 to 30 epochs, reached $\mlabClrsOff$ pointer
accuracy and used 92 of a 120-minute budget on one attempt; the cell with
the file, bound to a hundred epochs by a clause written without reference to
the budget, submitted nothing in three. Instructions therefore make
execution fail more often, and their net effect is positive only where the
prescribed tool gains enough to cover those failures; in a harness without a
repair loop the losses are larger (Section~\ref{sec:abl-terminus}). If an
instruction file bundles an override that helps with one that hurts, and the
mix of task families differs between studies, aggregate ablations will
report inconsistent effects, which is the disagreement noted in
Section~\ref{sec:related}.
