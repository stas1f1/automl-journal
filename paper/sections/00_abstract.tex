Agentic systems built on large language models are increasingly used to
automate machine learning. Which part of such a system its accuracy comes
from is unclear: the language model, the harness around it, or the expert
instruction file (an agent skill) it is given. We separate the three. All
experiments use one open-weight language model with 31 billion parameters and three harnesses:
FEDOT.LLM, a fixed-stage workflow over an AutoML library; AutoDS-Tools, a
six-agent system; and Terminus-2, a minimal shell agent. To compare the
agents with expert practice, accuracy is measured against the eighteen
hyperparameter-tuned methods published with the TabReD benchmark, on a
per-task scale from 0 (weakest published method) to 1 (strongest). First,
without the AutoDS-Tools instruction file the mean scores of the three
harnesses are close ($\nTerminus$ to $\nFedot$) and no pairwise difference
is significant, although single tasks differ widely. Second, the
instruction file raises
AutoDS-Tools from $\nAutoDSOff$ to $\nAutoDS$, the level of tuned LightGBM,
on all eight tasks ($p=\stfileBothP$). The file does not transfer: in
another harness it ends \ktBothLost{} of 24 trials without a submission,
and from a working script it leaves three of eight tasks without one. Third, the gain comes from naming an AutoML
library that tunes its models; an agent writing its own code fits one
untuned gradient-boosting model. The strongest published method
($\nBest$) remains out of reach. In practice, the harness decides
reliability and run time, delegating to an AutoML library decides accuracy,
and an instruction file must be tested with its harness.
