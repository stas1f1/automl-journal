Agentic systems built on large language models are increasingly used to
automate machine learning, yet it is unclear which part of such a system
its accuracy comes from: the language model, the harness around it, or the
expert instruction file (an agent skill) it is given. Published systems
change all three at once. We separate the three factors. All experiments use one open-weight language
model with 31 billion parameters and three harnesses: FEDOT.LLM, a
fixed-stage workflow over an AutoML library; AutoDS-Tools, a six-agent
system; and Terminus-2, a minimal shell agent. To compare the agents with
expert practice, accuracy is reported relative to the eighteen
hyperparameter-tuned methods published with the TabReD benchmark, on a scale
from 0 (weakest published method) to 1 (strongest).
First, the harness has little effect on accuracy: without the instruction
file the three harnesses lie within $\spanArch$ of each other, and no
pairwise difference is significant. Second, the instruction file accounts
for the gain: it raises AutoDS-Tools from $\nAutoDSOff$ to $\nAutoDS$, the
level of tuned LightGBM, on all eight tasks ($p=\stfileBothP$). This gain
does not transfer: in another harness the same file leaves half or more of
the runs without a result, and when the task starts from a working script
it leaves three of eight tasks without one. Third, no agent searches over
hyperparameters, and the strongest published method ($\nBest$) remains out
of reach. In practice, the harness decides reliability and run time, the
instruction file decides accuracy, and the file must be evaluated together
with its harness.
