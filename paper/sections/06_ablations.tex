\subsection{Harness alone: the instruction file removed}
\label{sec:abl-harness}

Of the three harnesses only AutoDS-Tools has an instruction file that can
be switched off. With it off, the three are compared directly (Figure~\ref{fig:ablations},
first three rows). Terminus-2 scores $\nTerminus$, AutoDS-Tools
$\nAutoDSOff$ and FEDOT.LLM $\nFedot$, and no pairwise difference is
significant. On the same image AutoDS-Tools is ahead of Terminus-2 on
\starchAutoDSvsTerminusWins{} of 8 tasks, a small and consistent lead.
FEDOT.LLM differs from both on single tasks in both directions.

\subsection{The instruction file}
\label{sec:abl-file}

\paragraph{Inside AutoDS-Tools}
The file has two parts, the library instruction and the discipline
instruction (Section~\ref{sec:file}). Table~\ref{tab:grid} switches each of
them on or off, which gives four cells of 24 trials that differ only in the
instruction file. The whole file raises the mean normalised score of
AutoDS-Tools from $\nAutoDSOff$ to $\nAutoDS$ and improves all eight tasks
(Figure~\ref{fig:ablations}). The gain comes from the library instruction.
Alone it gives $\nGridTool$, the level of tuned XGBoost, and the discipline
instruction alone gives $\nGridDisc$. In the task metrics the library
instruction gains most on \texttt{ecom-offers} ($\gridToolEcom\%$ ROC-AUC)
and changes every other task by less than $1\%$. With the library instruction
AutoDS-Tools calls LightAutoML~\citep{vakhrushev2021lightautoml} in every
trial that left a trace. Without it the agent writes LightGBM, XGBoost or
CatBoost by hand in every trial (Section~\ref{sec:spontaneous}). Naming the
library lengthens the fit: the median trial takes $\gridToolMin$ minutes
against $\gridNeitherMin$ without the file. With its file, AutoDS-Tools
scores $\gapAgentsShip$ above Terminus-2. The file accounts for
$\layerWorthNorm$ of this lead and the harness for $\gapAgentsOff$.

\paragraph{Appended to Terminus-2}
\label{sec:abl-terminus}
To test the file in a second harness we appended the byte-identical parts to
the Terminus-2 task statement and ran 24 trials per cell
(Table~\ref{tab:kdiscterm}). Accuracy does not change where it can be
measured. The number of trials that end without a submission does: it rises
from \ktNeitherLost{} of 24 without the file to \ktBothLost{} with both
parts, \ktDiscLost{} with the discipline instruction and \ktToolLost{}
with the library instruction. With the file the median trial takes \ktToolMin{} to
\ktBothMin{} minutes against \ktNeitherMin{} without it. None of these trials
reached the time limit. In each case the
agent started a fit, saw that the terminal had stopped producing output,
assumed that reporting was broken and marked the task complete.
\input{tables/kdiscterm}

Two paragraphs of the discipline instruction cause its losses. One offers a
hundred epochs as a starting budget. The other tells the agent to assume it
has ``hours, not minutes'' and that a training phase finishing ``within a
couple of minutes'' signals undertraining, while a trial without the file is
over in two and a half minutes. With the two paragraphs deleted, no trial of
24 is lost. With the library instruction the fit is long because LightAutoML
runs for many minutes. There the discipline text partly prevents the losses,
since it tells the agent that a long-running job is normal. Inside
AutoDS-Tools the same four cells lost at most one trial of 24.

\paragraph{From a working script}
\label{sec:abl-script}
Every MLAgentBench task starts from a working script. The two AutoDS-Tools
columns of Table~\ref{tab:mlab} switch the whole file there. On
\texttt{clrs}, \texttt{fathomnet} and \texttt{feedback} the cell without the
file scores in every attempt, and the cell with the file submits nothing in
any attempt, each attempt exhausting the agent budget. Only
\texttt{ogbn-arxiv} gains by more than the spread of either cell, and
\texttt{amp-parkinsons} gets worse. The file replaces a decision that the
supplied script had already made. The count of three tasks is a lower bound
on the cost of the file, since the repair loop of AutoDS-Tools absorbs part
of it (Section~\ref{sec:friction}). The two benchmarks differ in tasks,
metrics and budgets as well as in starting point, so the two outcomes are
compared without pooling.

The effect of the file therefore depends on the harness and on the starting
point: it adds accuracy in the harness it was written for, on tasks solved
from scratch, and elsewhere it costs submissions.

\subsection{Container image}
\label{sec:abl-image}

Running Terminus-2 on the enriched image built for AutoDS-Tools changes the
mean normalised score by $\stimageDiff$, inside the spread of the harness
across attempts. In all 24 trials the agent used none of the three libraries
the image pre-installs and wrote gradient boosting by hand, as on the stock
image.

\subsection{Language model}
\label{sec:abl-language-model}

We replaced the language model under each harness and kept tasks, image and
instructions unchanged. Accuracy moves without a consistent direction. Under
AutoDS-Tools the smaller gemma-4-26b-a4b changes the normalised
score by $\stautodsSmallDiff$ and glm-4.7 by $\stautodsBigDiff$.
Under Terminus-2 the smaller model gives $\sttermSmallDiff$ and
glm-4.7 $\sttermBigDiff$, almost all of it from one task: on
\texttt{sberbank-housing} the stronger model replaced gradient boosting with
a random forest and lost $46\%$ of RMSE. Reliability moves in opposite
directions for the two harnesses. Under Terminus-2 trials without a
submission fall from \axTerminusSmallLost{} of 24 to \axTerminusBigLost{} as
the language model grows. Under AutoDS-Tools they are lowest at the model
the system was built with (\axAutoDSRefLost{} of 24) and rise on both sides
(\axAutoDSSmallLost{} and \axAutoDSBigLost{} of 24). With glm-4.7,
\axAutoDSBigCut{} of its 24 trials reach the one-hour limit against
\axAutoDSRefCut{} with gemma-4-31b. Under
Terminus-2 the price of a cell of 24 trials varies \axPriceSpread$\times$
across the three language models.
