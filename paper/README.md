# Черновик статьи в FGCS

in Automated Machine Learning**

## Сборка

```
cd paper
python3 make_tables.py     # таблицы и макросы чисел из данных
python3 make_figures.py    # рисунки figures/fig_*.pdf из тех же данных
latexmk -pdf main.tex
```

`elsarticle.cls` и `.bst` взяты с CTAN и лежат рядом, потому что в системном
texlive их не было. Всё остальное стандартное.

## Числа

Все числа живут в словарях наверху `make_tables.py`. Строка FEDOT.LLM на TabReD
с 22.09 при полной точности (ссылки на задания Harbor Hub в
`result_files/DATA_SOURCES.md`); `precision_check.py` устарел. После новых экспериментов
правите словари, гоняете оба скрипта, пересобираете. Проза берёт числа из
макросов `tables/numbers.tex` (функция `table_numbers`). Литералами остались
только числа, которых нет в данных скрипта: ось модели в нормированной шкале,
кейсы, старые одиночные прогоны.

В статью входят таблицы `leaderboard`, `grid`, `axis`, `cost`, `mlabhead`,
`ktool`, `kdiscterm`, `cases` и макросы `numbers`. Данные кейсов лежат в
словарях `CASES*` того же скрипта; их источник `result_files/cases_terminus_2026-09-10.json`
(скрипт `runs/autods-tabred/collect_cases.py`). Остальные файлы в `tables/`
(`normalized`, `noise`, `clauses`, `greenfield`, `layersplit`, `matched`,
`discipline`) генерируются по-прежнему, но в текст не включены: их место
заняли рисунки и макросы. Они пригодятся для дополнительных материалов.

## Пометки в тексте

- `\todo{...}`: красным, требует работы над текстом или проверки.
- `\pending{...}`: синим, ждёт результатов прогона.

## Незавершённые прогоны

`make_tables.py` принимает `None` в любой строке `AGENTS`: пропущенная задача
даёт `--` в ячейке, средний ранг считается по отработавшим задачам и получает
надстрочный индекс с их числом. Результат `collect.py` можно вставлять по ходу
прогона, не дожидаясь всех 24 испытаний.

```bash
python3 ../runs/autods-tabred/collect.py ../runs/autods-tabred/jobs --only=full
# вставить строку "AutoDS-Tools": [...] в AGENTS и пересобрать
```
